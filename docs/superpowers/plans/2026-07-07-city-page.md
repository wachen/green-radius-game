# Public /city/ Page + Cached Aggregate-Only /api/city Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make community progress public: a `/city/` page showing the whole city's aggregate Green Radius, fed by a new public `GET /api/city` Worker route that is edge-cached and structurally incapable of leaking camp names, emails, or free text.

**Architecture:** The Worker grows one route, `GET /api/city`, that reuses the existing admin read pipeline (Apps Script `doGet` → `shapeAdminRows` → `AdminAggregate.computeAggregates`) but rebuilds its JSON response **field-by-field from an allowlist** (count, tally %, sector averages, this-week momentum, per-question intensities). The response is cached in the colo cache (`caches.default`) with a 5-minute freshness window checked in code via an embedded `generatedAt` timestamp; the stored entry lives 1 day so an upstream outage serves stale data marked "as of <time>". The page itself is a new static `/city/index.html` built exactly like `/result/` (vendored runtime, in-browser Babel, `RadialBadge` in aggregate `intensities` mode as the hero), plus one "See the City's Progress" link on the home screen.

**Tech Stack:** Cloudflare Worker (ES module, esbuild-bundled by wrangler), React 18 UMD + `@babel/standalone` (vendored, no build), Cache API (`caches.default`).

## Global Constraints

- **No build step, no test runner, no CI.** The only automated gate is `bun build <file> --external react --external react/jsx-runtime --external react/jsx-dev-runtime > /dev/null` (exit 0 = clean parse; a "could not resolve react" style message for the jsx file is expected and fine). Everything else is verified with `npx wrangler dev` + `curl` + a browser/Playwright.
- **Merging to `main` deploys to production instantly; HSTS preload is active.** Work on a branch, open a PR (squash-merged, 0 approvals required).
- **The Worker must degrade gracefully.** Missing secrets or a dead Apps Script must never break the static site; `/api/city` must return a well-formed degraded response, never throw.
- **Privacy is structural.** `/api/city` must never emit `campName`, `leadName`, `email`, `resultUrl`, `answers`, notes, or the aggregate `leaderboard`. Build the response object field-by-field; never spread the aggregate.
- **Copy style: no em dashes** in user-facing strings; match the surrounding tone.
- **`.assetsignore` controls what is served.** `city/` must be **served** — do NOT add it to `.assetsignore`. Do not touch `run_worker_first` (`/api/city` matches no asset so the Worker already runs for it).
- **Babel shared scope:** components in `green-radius.jsx` (`RadialBadge`, `SectorIcon`) are referenced by **bare name** from other `<script type="text/babel">` blocks. Plain-script globals are `window.SECTORS`, `window.AdminAggregate`, etc.
- **Bump `APP_VERSION`** (in `green-radius.jsx`, currently `'v49'`) to the PR number once the PR exists (expected `'v52'`; confirm against the actual PR number before merge).
- **Secrets** (`SHEETS_WEBAPP_URL`, `SHEETS_SHARED_SECRET`, `RESEND_API_KEY`) and their values must never be committed or echoed into any file. Local testing uses the existing git-ignored `.dev.vars`.
- The three docs that must stay truthful: `docs/architecture.md` (wiring changes), `CLAUDE.md` (route list), `CONTRIBUTING.md` (file layout).

// Shared read path for the admin viewer and the public city tally: proxy the
// Apps Script doGet and hand back the raw rows. Never throws — every failure
// mode collapses to { rows: null, reason } so both callers can degrade.
async function fetchSheetRows(env) {
  if (!env.SHEETS_WEBAPP_URL) return { rows: null, reason: 'no_backend' };
  const u = `${env.SHEETS_WEBAPP_URL}?mode=responses&secret=${encodeURIComponent(env.SHEETS_SHARED_SECRET || '')}`;
  const r = await fetch(u, { redirect: 'follow', signal: AbortSignal.timeout(UPSTREAM_TIMEOUT_MS) }).catch(() => null);
  if (!r || !r.ok) return { rows: null, reason: 'sheet_unavailable' };
  const data = await r.json().catch(() => ({}));
  // A 200 with a non-array payload means the Apps Script returned an HTML error/
  // login page or {ok:false,...} (e.g. a rotated secret) — treat it as a failure
  // so callers show a retryable error instead of a misleading "No camps yet".
  if (!Array.isArray(data.rows)) return { rows: null, reason: 'sheet_bad_payload' };
  return { rows: data.rows, reason: null };
}

- [ ] **Step 4: Add the city handler**

Add after `handleAdminResponses`/`shapeAdminRows`:

```js
// ── Public city tally: aggregate-only, colo-cached ───────────────────────────
// GET /api/city is the one public read path. Two hard rules:
//  1. PRIVACY IS STRUCTURAL. The response is rebuilt field-by-field below —
//     never spread the aggregate (computeAggregates includes a leaderboard
//     with camp names/result URLs, and future fields must stay private by
//     default). Nothing identifying a camp may appear here.
//  2. THE SHEET IS PROTECTED BY THE CACHE. Fresh responses are stored in the
//     colo cache for a day but treated as fresh for only 5 minutes (checked
//     in code via generatedAt — the Cache API can't serve entries past their
//     max-age, so freshness lives in the body). Result: at most ~1 sheet hit
//     per colo per 5 minutes, and an Apps Script outage serves the stale
//     entry (marked stale:true, client shows "as of <time>") instead of 503.
const CITY_FRESH_MS = 5 * 60 * 1000;
const CITY_CACHE_KEY = 'https://greenradi.us/api/city';

async function handleCity(env, ctx) {
  const cache = caches.default;
  const cacheKey = new Request(CITY_CACHE_KEY);
  const hit = await cache.match(cacheKey).catch(() => null);
  const cached = hit ? await hit.json().catch(() => null) : null;
  if (cached && Date.now() - cached.generatedAt < CITY_FRESH_MS) return cityJson(cached);

  const fresh = await computeCityBody(env);
  if (fresh) {
    ctx.waitUntil(cache.put(cacheKey, new Response(JSON.stringify(fresh), {
      headers: { 'Content-Type': 'application/json', 'Cache-Control': 'public, max-age=86400' },
    })));
    return cityJson(fresh);
  }
  if (cached) return cityJson({ ...cached, stale: true });
  return json({ error: 'unavailable' }, 503);
}

function cityJson(body) {
  return new Response(JSON.stringify(body), {
    status: 200,
    headers: { 'Content-Type': 'application/json', 'Cache-Control': 'public, max-age=60' },
  });
}

// The allowlist. Aggregate numbers only; see the privacy rule above.
async function computeCityBody(env) {
  const read = await fetchSheetRows(env);
  if (!read.rows) return null;
  let agg;
  try {
    agg = AdminAggregate.computeAggregates(shapeAdminRows(read.rows), GameData.SECTORS, Date.now());
  } catch { return null; }
  return {
    generatedAt: Date.now(),
    count: agg.count | 0,
    totalYes: agg.totalYes | 0,
    totalPossible: agg.totalPossible | 0,
    tallyPct: +agg.tallyPct || 0,
    hasAnswers: !!agg.hasAnswers,
    thisWeek: (agg.momentum && agg.momentum.thisWeek) | 0,
    sectorAverages: agg.sectorStandings.map(s => ({ id: String(s.id), avg: +s.avg || 0 })),
    intensities: agg.intensities ? Object.fromEntries(SECTOR_IDS.map(id => [id, {
      levels: ((agg.intensities[id] && agg.intensities[id].levels) || []).map(l => l.map(v => +v || 0)),
    }])) : null,
  };
}
```
