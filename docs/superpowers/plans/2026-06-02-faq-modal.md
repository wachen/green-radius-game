# Home-page FAQ modal — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a centered blue "FAQ" button to the home screen that opens a dismissable, all-expanded Frequently Asked Questions modal, and swap the six sector icons for the cleaner Lucide glyphs.

**Architecture:** All changes live in the single file `green-radius.jsx` (the app is one in-browser-Babel React file; `index.html` mounts `<GreenRadiusGame/>` and defines the shared keyframes and `PALETTE`). The FAQ modal reuses the existing `QuestionModal` overlay/card styling and the `qm-fade` / `qm-up` keyframes (which already have `prefers-reduced-motion` overrides). FAQ state lives inside `ModePicker`, which only mounts on the home screen (`phase === 'pick-mode'`), so the trigger is home-only with no extra guards. The icon swap is a self-contained rewrite of the `SectorIcon` component.

**Tech Stack:** React 18.3.1 (UMD global, no JSX imports), `@babel/standalone` in-browser compilation, no bundler, no test runner. Hooks are destructured from the global `React` at `green-radius.jsx:4` (`useState`, `useEffect`, `useRef`, `useMemo`, `useCallback`).

## Verification approach (read first)

This project has **no automated test runner** and **no build step** (it is intentionally a no-build, CDN-global app — see the spec's "out of scope"). So the usual write-a-failing-test loop does not apply. Every task is verified two ways instead:

1. **Parse gate (compile check).** From the repo root, run:
   ```bash
   bun build green-radius.jsx --external react --external react/jsx-runtime --external react/jsx-dev-runtime > /dev/null && echo "PARSE OK" || echo "PARSE FAILED"
   ```
   Expected: `PARSE OK`. A JSX/syntax error exits non-zero, prints the offending line with a caret, and you'll see `PARSE FAILED`. (The `> /dev/null` just discards the bundled JS; we only care that it parses. `react` is correctly unresolved-but-external, which is why the `--external` flags are required.)

2. **Manual browser check.** Serve the folder and click through. In a separate terminal (or background process), from the repo root:
   ```bash
   python3 -m http.server 8000
   ```
   Then open `http://localhost:8000`. (`file://` will not work — the browser blocks cross-origin `<script src>` reads.) Each task below lists exactly what to look for.

Commit after each task once both checks pass.

function FaqModal({ onClose, palette }) {
  const closeRef = useRef(null);
  useEffect(() => {
    closeRef.current?.focus();
    const onKey = (e) => { if (e.key === 'Escape') onClose(); };
    window.addEventListener('keydown', onKey);
    return () => window.removeEventListener('keydown', onKey);
  }, [onClose]);

  return (
    <div
      onClick={onClose}
      style={{
        position: 'fixed', inset: 0, zIndex: 50,
        background: 'rgba(20,12,8,0.55)', backdropFilter: 'blur(6px)',
