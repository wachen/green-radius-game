# Minimal on purpose. Cloudflare's "Manage your robots.txt" setting is ON for this
# zone, so Cloudflare MERGES its managed AI-crawler block into this file at the
# edge, appending it under a "# END Cloudflare Managed Content" marker and leaving
# the directives below intact. This file therefore carries only the one thing
# Cloudflare cannot know: where the sitemap lives.
#
# Do not restate the AI-crawler Disallow rules here. Enforcement is a separate
# dashboard setting (Security Settings > Bot traffic > Block AI training bots) and
# works regardless of this file, so a hand-copied list here would only drift from
# whatever the dashboard actually says.
#
# Careful if that setting is ever switched off: Cloudflare injects robots.txt
# content only when the origin has no file of its own. With the setting off AND
# this file present, the content signals disappear entirely rather than being
# merged, and nothing warns you.
#
# Serving this as a static asset also keeps /robots.txt out of the Worker. With no
# file here, Cloudflare probed the origin and the Worker answered 404 about 26
# times a day, its single largest source of invocations once the WAF scanner rule
# landed. Crawlers never saw those 404s, but we still paid for them.
#
# /admin/ is intentionally not listed. It is gated by Cloudflare Access, and
# naming it here would only advertise the path.

User-agent: *
